Este repositorio fue creado como base para practicar el flujo de trabajo colaborativo en Git y GitHub:

- `README.md`: Descripción general de la actividad y registro de aportes.
- `COLABORADORES.md`: Lista de integrantes y sus párrafos de presentación.

## Aporte de Colaborador
**Nombre:** Jamile  
**Párrafo:**  
El uso de Git y GitHub facilita enormementee el trabajo colaborativo en el desarrollo de software, ya que permite que cada integrante trabaje en una rama independiente sin afectar el código principal. A través del flujo de ramas y Pull Requests, es posible revisar cambios, mantener un historial claro de versiones y fusionar las contribuciones de forma ordenada y segura.
