# Actividad 1: Trabajo Colaborativo Básico

Este repositorio fue creado como base para practicar el flujo de trabajo colaborativo en Git y GitHub:
1. Clonar un repositorio compartido.
2. Crear una rama propia (`git checkout -b <nombre-rama>`).
3. Modificar un archivo `.md` agregando nombre y un párrafo descriptivo.
4. Subir los cambios (`git push`) y generar un **Pull Request (PR)**.

## Estructura del proyecto
- `README.md`: Descripción general de la actividad y registro de aportes.
- `COLABORADORES.md`: Lista de integrantes y sus párrafos de presentación.
